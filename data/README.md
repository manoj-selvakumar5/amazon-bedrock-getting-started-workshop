# data/

- `policies/`: AnyCompany's travel and expense policy, seven short Markdown documents. Module 3 uploads them to Amazon S3 and ingests them into a Managed Knowledge Base.
- `expense_reports.json`: seven sample expense reports. `expected` is the verdict under the hand-typed rules in Module 2; `expected_with_policy` is the verdict under the full policy, used from Module 3 on.
